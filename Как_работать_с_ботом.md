# Материалы, фото и согласование

## Доступ через Telegram

Главный администратор управляет компаниями и доступом. Для работы с материалами используйте отдельный аккаунт **администратора компании**: эта роль позволяет и готовить, и согласовывать публикации.

Если такого аккаунта ещё нет, создайте приглашение в разделе «Доступы», выберите роль «Администратор компании» и откройте ссылку в отдельном браузере. Введите данные рабочего аккаунта. В его кабинете нажмите значок «Привязать Telegram» рядом с именем. Выберите «Создать ссылку», затем «Открыть бота» и нажмите «Запустить» в Telegram. Бот получает ваш ID из сообщения.

## Фото

Прикрепите фотографии и факты для публикации. Отправляйте подборку одним альбомом.

Бот подтвердит получение текста и число вложений. В одном сообщении будет обновляться этап: загрузка вложений, подготовка изображения, подготовка текста, ожидание уточнения или готовность. При долгом ожидании раз в 30 секунд появляется прошедшее время. Подтверждение получения означает, что сообщение принято ботом; отправка модели начинается на соответствующем этапе. При ошибке появится уведомление.

- `#фото*` — оставить исходные фотографии без редактирования и генерации. Звёздочка обязательна: обычный `#фото` не считается командой.
- `#изменить*` — обработать приложенное фото. После команды опишите изменения.
- `#создать*` — создать иллюстрацию с нуля. После команды опишите результат. Для работы на основе приложенного фото используйте `#изменить*`.

Пример без обработки:

```text
20 ноября в 12:00 в спортивном зале состоится турнир для сотрудников.
Участвуют четыре команды. Запись у организатора до 18 ноября.
#фото*
```

Пример обработки:

```text
20 ноября в 12:00 в спортивном зале состоится турнир для сотрудников.
#изменить* Сохранить людей и форму на приложенном фото,
сделать фон светлее, использовать фирменные цвета.
```

Первый вариант изображения готовится с логотипом автоматически: ИИ выбирает цвет и один из четырёх углов. Приложение накладывает настоящий PNG с одинаковым отступом 3,5% ширины фото от обеих сторон угла; ширина знака обычно 35%. Чистая фотография сохраняется отдельно. Если результат не нравится, нажмите «Изменить логотип», выберите цвет («Основной цвет», «Белый», «Чёрный») и угол, затем «Применить». Фото и текст сохраняются, запроса к ИИ при ручной смене нет. Изменение отменяет прежнее согласование. Если автоматический подбор не удался, готовое фото сохраняется, а бот предлагает выбрать логотип вручную. Запрошенные надписи, плашки и игровые элементы создаёт модель по заданию после `#изменить*`. Для другой компании сначала настройте её собственные логотипы и цвета. Режим `#фото*` сохраняет оригиналы, включая отсутствие дополнительных надписей и логотипов.

При выборе цвета проверяйте всю область знака и названия, включая лампы, блики и окна. Основной зелёный — предпочтительный цвет; на однородном белом фоне подходит чёрный, на тёмном — белый. На смешанном фоне белый может теряться на светлых деталях, а чёрный — на тёмных. Окончательный выбор задаёт редактор кнопками.

В веб-кабинете откройте «Фотографии» в черновике и выберите режим «Исходные фотографии», «Создать изображение» или «Оформить фотографии». Цвета и логотипы находятся в настройках компании.

Для пробы выберите `gpt-6-sol`. В Responses API эта модель управляет отдельным инструментом создания изображения. Подготовка текста занимает один запрос, изображения с автоматическим подбором логотипа — два. Ручная смена логотипа выполняется локально и не расходует лимит запросов. Генерация не подтверждает факты о событии: перед согласованием проверьте текст и изображение.

## Согласование

Для проверки в личке канал подключать не нужно. Готовый комплект в боте сразу переходит на проверку. Администратор компании, согласующий или редактор с правом согласования видит «Одобрить», «Отклонить», «Изменить» и, для редактируемого логотипа, «Изменить логотип». «Одобрить» не публикует пост. Канал понадобится только для отправки; после его выбора пост нужно согласовать повторно. Редактор без права согласования может менять пост, но не одобрять его.

1. Отправьте материал. Если бот задаёт вопросы, ответьте на его сообщение. В чате сотрудников добавляйте упоминание бота.
2. Проверьте текст, фотографии, канал и время публикации.
3. В боте готовый комплект уже находится на проверке. В кабинете нажмите «На согласование».
4. Администратор компании, согласующий или редактор с правом согласования нажимает «Одобрить» в боте либо «Согласовать» в кабинете. «Отклонить» возвращает пост на доработку. «Изменить» запрашивает правки ответом на сообщение: у администратора и редактора бот обновляет текст; у согласующего сохраняет комментарий и возвращает пост редактору. Фотография и логотип при правках текста сохраняются.
5. После одобрения нажмите «Опубликовать» либо дождитесь назначенного времени. Любое изменение текста или изображения отменяет прежнее согласование.

Перед первой отправкой настройте тестовый канал и добавьте туда бота с правом публикации. Согласование само по себе не означает немедленную отправку в канал.

## Поручения и отчёты

В личном чате можно написать без команды:

```text
Предложи темы публикаций для сотрудников.
Составь план на следующую неделю.
Пришли отчёт за неделю.
Присылай отчёт по пятницам в 10:00.
Перенеси пост №3 на завтра в 15:00.
```

Каждую строку отправляйте отдельным запросом. Расписание и перенос поста требуют подтверждения кнопкой с датой, временем и часовым поясом компании. Если сведений не хватает, ответьте на уточняющее сообщение бота. Перенесённый пост нужно согласовать заново.

«Отключи отчёты» позволяет остановить расписание: бот покажет, какое именно. Если расписаний несколько, уточните номер. Разовый отчёт не включает регулярную рассылку. Для обычного текста без очевидного поручения бот предложит «Материал для поста» или «Поручение». Текст с префиксом `Материал для поста:` сразу обрабатывается как материал. Фотографии и альбомы работают по прежним правилам.

В кабинете можно включить «Сообщить в Telegram» при создании задачи или настройке регулярной задачи. Уведомление получает её создатель, пока у него есть доступ и сохранена исходная привязка Telegram. Для управления расписаниями отчётов откройте раздел «Отчёты».

## Компании и API

Главный администратор добавляет компании через список компаний. Кнопка «Убрать компанию» в настройках архивирует компанию: материалы сохраняются, работа и публикации останавливаются.

В настройках компании главный администратор выбирает «Источник ключей»: «Ключи компании», «Ключи Салаватстекло» или «Общие ключи». Для двух последних вариантов укажите месячный лимит запросов. Сами общие ключи вводятся в разделе «Общие ключи». Запросы учитываются у компании, которая их отправляет. Управление общими ключами, источником и выделенным лимитом доступно главному администратору.

Лимит запросов ограничивает число операций, а не сумму в рублях: стоимость текста и изображения отличается.

Право редактора включает администратор компании: «Сотрудники» → карточка редактора → «Согласование и публикация». При назначенном списке согласующих редактор должен входить в него. После отключения права старые кнопки согласования и публикации перестают выполнять действия.
