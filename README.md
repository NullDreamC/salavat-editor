# Редакция

Локальный кабинет для внутренних публикаций. Материалы и знания компании → уточнения → текст и изображение → согласование → Telegram, ВКонтакте или MAX.

Готовая сборка для Windows: [архив проекта](releases/salavat-editor-2026-11-14.zip), [SHA-256](releases/salavat-editor-2026-11-14.zip.sha256). В архиве сервер Python, собранный интерфейс, исходники и тесты. Порядок установки описан в [инструкции к сборке](docs/Сборка.md).

Новые разделы и оставшиеся подключения описаны в [статусе ТЗ](docs/Статус_ТЗ.md). Правила подключения ВКонтакте и MAX — в [инструкции](docs/API_соцсетей.md).

В Telegram теперь можно ставить задачи обычными фразами: «Предложи темы для сотрудников», «Составь план на следующую неделю», «Присылай отчёт по пятницам в 10:00». Перенос публикации и расписание бот уточняет и показывает для подтверждения. Неоднозначный текст предлагает отнести к материалу или поручению. [Поручения, уведомления и отчёты](docs/Поручения_и_отчёты.md).

На список тем можно ответить: «Создай пост с темой номер 5 и сгенерируй фото для поста». Результат — отдельный пост с текстом, изображением и логотипом, отправленный на согласование. Завершённые этапы сохраняются для повтора после ошибки.

В разделе «Отчёты» доступны предпросмотр, сохранённые снимки и ежедневные/еженедельные расписания. Отправку себе в Telegram или получателю настраивают отдельно. Для новых задач и регулярных задач есть настройка «Сообщить в Telegram», по умолчанию выключенная. Требуется привязка Telegram и подключённый бот.

## Знания, задачи и контент-план

«База знаний» хранит сведения о компании, правила стиля, ответы на частые вопросы и решения редакции. Черновики и архив не используются в новых запросах. Изменения сохраняются отдельными версиями. Текст можно ввести вручную, взять из материала или импортировать с HTTPS-страницы; импорт сначала попадает в черновик. Выжимка по «Салаватстекло» добавлена отдельно: профиль, история и три продукта используются в задачах, сведения о профсоюзе и здравпункте ждут подтверждения актуальности.

«Задачи» — сохранённые диалоги, подбор тем, стратегия внутренних коммуникаций, план и сценарии видео. Если не хватает сведений, задача показывает вопросы. Прерванный запрос можно повторить вручную. В личном диалоге с ботом доступны `/ask`, `/topics`, `/plan`, `/strategy`, `/video`; продолжение отправляется ответом на сообщение задачи. Обычный текст с фотографиями по-прежнему принимается как материал для поста.

«Контент-план» хранит предложения и связанные черновики. Кнопка создания поста переносит заголовок и источники; текст готовится отдельно с проверкой фактов. Во вкладке «Регулярные задачи» задаются время, дни и задание. Результат сохраняется в «Задачах». Расписание работает в часовом поясе компании, пропуск в пределах текущего дня догоняется один раз. Предыдущие дни не воспроизводятся. Автоматического согласования и публикации новых черновиков нет.

## Обращения и статистика

«Обращения» принимает ручные записи и комментарии из подключённых ВКонтакте/MAX. Ответ можно подготовить по базе знаний, изменить, согласовать и отправить. Настройка автоответов выключена по умолчанию: администратор разрешает конкретные ответы из раздела «Частые вопросы». Только точное совпадение вопроса после нормализации запускает такой ответ. Изменение записи FAQ требует нового разрешения. Неопределённый результат отправки блокирует повтор.

Мониторинг включается отдельно. Раз в 15 минут он проверяет до пяти последних публикаций приложения за 30 дней, импортирует доступные метрики и комментарии. Публикации, отмеченные опубликованными только после ручной сверки, не имеют подтверждённого времени отправки: их показатели загружаются вручную с указанной датой.

«Статистика» поддерживает замеры вручную, CSV/JSON и доступные показатели API. Неизвестные значения не заменяются нулями. Отчёт показывает покрытие, сравнение форматов и гипотезы; ER считается по охвату только для записей с достаточными данными. Для Telegram пока доступен ручной ввод и импорт. Рублёвый бюджет в настройках — ориентир, жёсткий ограничитель работает по количеству запросов.

## Согласование и площадки

В настройках можно назначить согласующих по ID. Если список пуст, согласуют все действующие администраторы и согласующие компании. Изменение текста, медиа, площадки, адреса или времени отменяет согласование. Публикация использует сохранённый согласованный комплект. Адрес ВКонтакте/MAX берётся из настройки подключения; после его изменения нажмите в посте «Взять адрес из настроек» и согласуйте заново.

Если исход отправки неизвестен, откройте «Проверить результат отправки», вручную проверьте площадку и укажите результат. Найденная публикация сохраняется с её ID; отсутствие публикации возвращает пост в черновики. Эта операция ничего не отправляет.

## Запуск

Требуются Python 3.12+ и Node.js 22+. В папке проекта:

```powershell
.\start.ps1 -Install
```

Повторный запуск: двойной щелчок по `start.cmd` или `.\start.ps1`. Адрес: http://127.0.0.1:8000. Сервер доступен только на этом компьютере. Не запускайте несколько экземпляров с одной базой.

При первом входе создайте главного администратора. Появятся три отдельных профиля компаний: «Салаватстекло» и две компании для настройки. Названия можно изменить. Установленных общих паролей нет.

## Роли и приглашения

- **Главный администратор** создаёт компании и управляет их настройками. В разделе «Доступы» видит только ID профиля, компанию, роль и статус. Может менять роли, отключать и включать доступ, создавать и отзывать приглашения. Имена, почта, Telegram ID, профили сотрудников, материалы и журнал компании ему недоступны через приложение. Он не задаёт и не сбрасывает пароли сотрудников.
- **Администратор компании** управляет её сотрудниками, ролями, настройками и публикациями. Доступ к другой компании требует отдельного приглашения. Нельзя отключить или понизить последнего администратора своей компании; сначала назначьте другого.
- **Редактор** готовит материалы и публикации. **Согласующий** проверяет, одобряет и отправляет публикации.

Чтобы назначить первого администратора компании, главный администратор выбирает компанию → «Доступы» → «Пригласить» → роль «Администратор компании». Передайте одноразовую ссылку получателю: он сам вводит имя, почту и пароль. Ссылка действует 7 дней и может быть отозвана. При локальном запуске она открывается на этом же компьютере; получатель использует отдельный браузер или приватное окно. Уже зарегистрированный сотрудник вводит свой действующий пароль.

Администратор компании может добавлять новые аккаунты в разделе «Сотрудники» или приглашать существующие. Если сотрудник работает в нескольких компаниях, его роли задаются отдельно. Главный администратор не может присоединить собственный главный аккаунт к компании как сотрудника.

При обновлении старый общий администратор становится главным: его автоматические членства в компаниях удаляются, сеансы завершаются. Сотрудники, их права, материалы и публикации сохраняются. Для компаний без своего администратора создайте приглашения.

## Пароли

Свой пароль: кнопка с ключом «Сменить пароль» рядом с профилем. Укажите текущий пароль и дважды новый (от 10 символов). Все сеансы завершатся; войдите с новым паролем.

Сброс сотруднику: «Сотрудники» → карточка сотрудника → «Сбросить пароль». Доступно администратору компании. Если у сотрудника есть доступ к компании, которой этот администратор не управляет, сброс запрещён: сотрудник меняет пароль самостоятельно. Это защищает доступ к другим компаниям. Главный администратор пароли сотрудников не сбрасывает. Свой пароль любой пользователь меняет через кнопку с ключом с проверкой текущего пароля. Открытые сеансы завершаются, материалы и права сохраняются.

## Рабочий порядок

1. В настройках компании выберите OpenAI или Yandex, укажите модель и ключ. Ключ из `OpenAI.txt` используется сервером только для основного профиля «Салаватстекло». Файл не раздаётся через сайт и исключён из Git.
   Список моделей загружается сервером через Models API. Для редактора оставлены модели для текстов; речь, Realtime, TTS, изображения, поиск и другие специальные модели скрыты. Кнопка рядом обновляет список. После изменения ключа или ID каталога сначала сохраните настройки. При ошибке текущая модель сохраняется. Для Yandex показаны текстовые модели каталога, включая Алису; ключу нужен доступ `yc.ai.models.viewer`. Наличие модели в каталоге OpenAI не гарантирует поддержку изображений и формата ответа редактора.
   В поле «Правила текстов» можно задать стиль и рубрики именно этой компании. Правила других компаний не передаются модели.
2. Добавьте текст, документ, фотографию или видео в «Материалы». Для видео нужен текст с фактами события. PDF без текстового слоя требует текстового описания.
3. Создайте пост из выбранных материалов и нажмите подготовку текста. Если сведений не хватает, ответьте на вопросы. Можно отредактировать пост вручную.
4. При необходимости создайте карточку, проверьте текст, вложения, канал и время. Отправьте комплект на согласование.
5. Согласующий одобряет или возвращает материал. Согласованный пост отправляется вручную или по заданному времени. Изменение комплекта отменяет согласование.

Без настроенного провайдера подготовка текста выдаёт понятную ошибку; программа не подставляет выдуманные демонстрационные результаты. Остальные операции с материалами и ручная редактура доступны.

## Telegram

Создайте отдельного бота для каждой компании через BotFather. Укажите токен, имя бота, ID тестового канала и ID чата сотрудников в настройках. Добавьте бота в тестовый канал с правом публикации. Сначала используйте только тестовый канал.

В карточках сотрудников укажите их числовые Telegram ID. Для получения личных уведомлений каждому нужно открыть бота и отправить `/start`. Бот использует polling, поэтому локальному запуску не нужен публичный адрес. Другой polling-процесс или установленный webhook у этого же бота мешает получению сообщений.

В общем чате должны одновременно выполняться три условия: настроенный чат, разрешённый отправитель и настоящее упоминание `@имя_бота` в сообщении. Ответ на уточнение в общем чате тоже должен содержать упоминание. В личном диалоге упоминание не нужно, но права пользователя проверяются.

Команды администратора в личном чате:

- `/allow 123456789` — разрешить передачу материалов сотруднику;
- `/remove 123456789` — убрать его доступ через Telegram;
- `/list` — показать сотрудников.

Согласование и отклонение доступны кнопками. `/reject НОМЕР причина` возвращает пост на доработку с комментарием. Кнопки привязаны к версии поста; старое уведомление не согласует изменённый материал.

Telegram принимает здесь до 10 изображений/MP4 в одном комплекте. Подпись с медиа ограничена 1024 символами, текст без медиа — 4096. Программа не обрезает пост незаметно: слишком длинный текст нужно сократить перед согласованием. Из Telegram загружаются файлы до 20 МБ; через кабинет — до 40 МБ. MOV/WEBM можно хранить как материалы, но для публикации видео нужен MP4.

## Telegram WebApp

Подключён `@SalavatNews_bot`. Токен из `TGAPI.txt` сохранён через Windows DPAPI. `/start` открывает кнопки «Кабинет», «Передать материал», «Публикации», «Мой ID» и «Помощь» с учётом роли. Пользователь без разрешённого Telegram ID видит только вход в кабинет, свой ID и помощь. Данные сотрудников и публикации ему недоступны.

В WebApp используются существующие почта и пароль. Telegram ID сам по себе не даёт доступ к веб-аккаунту. С отдельного разрешения владельца настроен временный HTTPS-туннель **localhost.run**. Адрес хранится в `.runtime/webapp.json`; сервер принимает только этот точный хост и локальные адреса. Сохраняются проверки сеанса, ролей и происхождения запросов. HTTPS cookies защищены Secure/HttpOnly; разрешено открытие внутри Telegram Web. Число попыток входа ограничено.

Туннель работает, пока включены компьютер, кабинет и SSH-процесс. Бесплатный адрес может измениться. Повторный запуск, когда прежний туннель остановлен:

```powershell
& 'C:\Program Files\Git\usr\bin\ssh.exe' -T -F .runtime/ssh-tunnel-config salavat-webapp | Out-File -Encoding utf8 .runtime/ssh-tunnel.log
```

Для автоматического обновления адреса из журнала SSH запущен `server.tunnel_watch`; кабинет и меню бота подхватывают смену без перезапуска. При повторном запуске перенаправляйте вывод SSH в `.runtime/ssh-tunnel.log` и запускайте наблюдатель отдельным процессом. Старые открытые окна WebApp после смены адреса нужно закрыть и открыть заново кнопкой «Кабинет».

Команда наблюдателя в отдельном окне: `.\.venv\Scripts\python.exe -m server.tunnel_watch`.

Для ручного назначения адреса или первичного подключения бота:

```powershell
.\.venv\Scripts\python.exe -m server.setup_telegram --company 1 --webapp-url https://НОВЫЙ-АДРЕС
```

В текущей сети Telegram и провайдеры используют уже установленный локальный HTTP-прокси `127.0.0.1:10808`. Настройка находится в `.runtime/network.json`, параметры Windows не менялись. Прокси должен работать. В сети с прямым доступом этот файл можно удалить. Туннель localhost.run подключается напрямую.

## Календарь

Включается отдельно для каждой компании. События можно добавить вручную; при подготовке поста модель может извлечь событие с точной датой и подтверждающим фрагментом источника. В день события бот просит прислать материалы. Выключатель останавливает извлечение событий и напоминания; расписание уже согласованных публикаций работает независимо.

Локальные напоминания и отправка выполняются только пока сервер и компьютер включены. Для постоянной работы приложение необходимо перенести на сервер. Часовой пояс задаётся у компании.

## Данные и расходы

Данные и вложения хранятся в `.runtime/`. Сделайте резервную копию этой папки при остановленном сервере. На Windows сохранённые ключи защищены DPAPI текущего пользователя: перенос базы на другую учётную запись требует повторного ввода ключей. Пароли хешируются; ключи не возвращаются браузеру.

Текст готовит выбранный провайдер. Создание и обработка изображений выполняются отдельно через OpenAI по явной команде редактора. Учитываются запросы и возвращённые провайдером токены. Ограничение числа запросов действует в приложении. Поле бюджета в рублях — плановый ориентир, не точный биллинг и не гарантированный денежный стоп: установите денежные ограничения также в кабинете провайдера.

Главный администратор назначает компании свои ключи, ключи «Салаватстекло» или общий набор ключей. Для двух общих вариантов обязателен положительный месячный лимит. Учёт ведётся отдельно у каждой компании за календарный месяц UTC; текст и изображение считаются отдельными запросами. Администратор компании не может увеличить общий лимит или сменить источник ключей. Удаление компании из списка архивирует её, сохраняет материалы и останавливает работу.

После неопределённого результата отправки программа не повторяет публикацию автоматически: сообщение могло уже появиться в канале. Проверьте канал и запись в журнале до повторных действий.

## Оформление и редактура

Интерфейс использует предоставленный шрифт и фирменные цвета. Карточки собираются локально по трём фиксированным компоновкам. По команде редактора можно создать иллюстрацию или обработать фото через OpenAI. В первом варианте ИИ автоматически выбирает цвет и угол логотипа; приложение накладывает настоящий PNG шириной около 35% фото с отступом 3,5% от обеих сторон угла. Чистое изображение сохраняется для ручной замены логотипа кнопками, без новой генерации и без изменения текста. Готовый пост в боте сразу поступает на проверку с кнопками «Одобрить», «Отклонить», «Изменить», «Изменить логотип» (по правам пользователя). Если автоматический подбор логотипа не удался, фото сохраняется для ручной настройки. Смена текста или логотипа отменяет прежнее согласование. Для «Салаватстекло» доступны основной зелёный, белый и чёрный; при подборе учитываются все детали под знаком, включая лампы, блики и окна. Монтаж видео не реализован.

Команда `#фото*` сохраняет подборку без обработки. `#изменить*` задаёт обработку приложенного фото, `#создать*` — создание с нуля; задание для изображения пишется после команды, факты для текста — перед ней. Без выбора режима бот уточняет действие. Порядок привязки Telegram и согласования описан в [инструкции](Как_работать_с_ботом.md).

Постоянная инструкция модели берётся из `Инструкция_ИИ_редактору.md`. Редакционные основания и примеры — в `Редакционные_правила_для_постов.md`. ИИ запрашивает недостающие сведения, но его самопроверка не гарантирует истинность текста: итоговый комплект проверяет человек.

## Границы текущей реализации

Реализуемая площадка публикации — Telegram. ВКонтакте и MAX, сбор статистики площадок, анализ комментариев и автоматические ответы ещё не подключены. Подписка ChatGPT не используется как способ оплаты API: подключение выполнено через отдельный ключ OpenAI API. Локальная модель пока не подключена.

Внешний доступ сейчас предназначен для тестирования. Для постоянной работы нужны стабильный домен, развёртывание с одним фоновым обработчиком, резервирование данных и проверка эксплуатационных ограничений.

## Разработка и проверка

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
cd web
npm.cmd run build
```

Проверки серверной логики используют изолированные базы и подставные ответы сервисов. Они не публикуют сообщения и не расходуют платный API. Проверка настоящего Telegram требует токена и тестового канала.

Для браузерной проверки: установите `requirements-dev.txt` и запустите `.\.venv\Scripts\python.exe tests/browser_smoke.py`. Скрипт использует установленный Microsoft Edge в скрытом режиме, временную базу и порт 8001. Результаты сохраняются в `test-results/`; платных запросов и публикаций нет.

Официальные интерфейсы: [OpenAI Responses](https://developers.openai.com/api/reference/resources/responses/methods/create), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Yandex Responses](https://aistudio.yandex.ru/en/docs/ai-studio/api/Responses/createResponse), [мультимодальные запросы Yandex](https://aistudio.yandex.ru/en/docs/ai-studio/operations/generation/multimodels-request-responses), [Telegram Bot API](https://core.telegram.org/bots/api).

Дополнительно: [Models API OpenAI](https://developers.openai.com/api/reference/resources/models/methods/list), [список моделей Yandex](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/models/get), [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [временный HTTPS localhost.run](https://localhost.run/docs/http-tunnels).
