# Сборка для Windows

Архив `salavat-editor-2026-11-14.zip` содержит сервер, исходники, тесты, фирменные ресурсы и уже собранный интерфейс `web/dist`. Для запуска нужен Python 3.11 или новее; сборка проверена на Python 3.14.

Распакуйте архив в отдельную папку и откройте в ней PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\start.ps1
```

Кабинет откроется по адресу `http://127.0.0.1:8000`. При первом запуске создайте главного администратора, затем пригласите администратора компании. Ключи провайдеров и Telegram подключаются в настройках. Аккаунты, база данных, загруженные материалы, токены и временный HTTPS-адрес в сборку не включены.

Для пересборки интерфейса нужен Node.js:

```powershell
cd web
npm ci
npm run build
```

Проверки из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

После изменения исходников запустите `python scripts/package_release.py`: он соберёт архив из разрешённого списка файлов, проверит отсутствие локальных API-ключей и создаст контрольную сумму в `.runtime/release`. Содержимое `BUILD-MANIFEST.json` позволяет сверить состав архива.
