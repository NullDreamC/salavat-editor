# Подключения ВКонтакте и MAX

Администратор компании или главный администратор указывает числовой идентификатор площадки, токен и включает подключение в настройках компании. `configured` означает, что идентификатор и токен сохранены. Доступ и права проверяются площадкой при запросе. При замене токена новое значение сохраняется в хранилище секретов Salavat. Пустое поле сохраняет текущий токен, а `null` в API очищает токен и выключает подключение.

## ВКонтакте

Для стены сообщества укажите его числовой ID. Salavat сохраняет его в формате `-123`, который VK API использует для `owner_id`. Для `wall.post`, `photos.getWallUploadServer`, `photos.saveWallPhoto` и `video.save` требуется пользовательский токен с доступом к соответствующим методам и правами публикации от имени сообщества. Salavat использует API 5.199. Фото загружается в JPEG, PNG или GIF через сервер, полученный от `photos.getWallUploadServer`. Видео проходит через `video.save` и добавляется в запись как вложение. [Схема VK API](https://github.com/VKCOM/vk-api-schema), [официальный пример загрузки фото](https://github.com/VKCOM/vk-java-sdk#8-api-requests), [официальный SDK для загрузок](https://github.com/VKCOM/vk-java-sdk/blob/master/sdk/src/main/java/com/vk/api/sdk/actions/Upload.java).

В Salavat действуют локальные пределы для ВКонтакте — 16 384 символа в записи, 10 фото и видео и 40 МиБ на файл. Поддерживаются видео MP4, MOV, WebM и MKV. Площадка дополнительно проверяет параметры файлов и права доступа. Аналитика получает счётчики просмотров, отметок «Нравится», комментариев и репостов из `wall.getById`. `wall.getComments` загружает страницу комментариев к записи, `wall.createComment` публикует согласованный ответ от имени сообщества. [Методы стены VK API](https://github.com/VKCOM/vk-api-schema/blob/master/wall/methods.json).

## MAX

Укажите числовой `chat_id` и токен бота MAX. Добавьте бота в нужный канал или групповой чат и выдайте право публикации. Для комментариев к постам бот должен быть администратором канала с правом `read_all_messages`. Для ответа требуется также право `write`, а в канале должны быть включены комментарии. [Добавление бота](https://dev.max.ru/docs-api/use-cases/bot-in-chats-and-channels), [как получить ID](https://dev.max.ru/docs-api/use-cases/getting-chat-id/), [отправка комментария](https://dev.max.ru/docs-api/methods/POST/messages/-messageId-/comments/).

Salavat обращается к `platform-api2.max.ru` с токеном в заголовке `Authorization`. При ошибке проверки TLS настройте доверие к официальной цепочке Минцифры в окружении процесса приложения. Python HTTPX поддерживает `SSL_CERT_FILE` с абсолютным путём к PEM-пакету доверенных сертификатов. Сохраните в пакете сертификаты, которые нужны остальным используемым HTTPS-ресурсам. [Документация MAX](https://dev.max.ru/docs-api/), [сертификаты Минцифры на Госуслугах](https://www.gosuslugi.ru/crt), [переменные окружения HTTPX](https://www.python-httpx.org/environment_variables/#ssl_cert_file).

MAX принимает до 4000 символов и до 12 фото и видео в публикации. Максимальный размер изображения — 50 МБ и 7680 × 7680 пикселей, видео — 250 МБ. Количество и размеры вложений считаются до отправки. Для канала API возвращает количество просмотров и может вернуть публичную ссылку. Счётчики реакций и репостов в API сообщения отсутствуют. [Отправка постов](https://dev.max.ru/docs-api/methods/POST/messages/), [медиафайлы](https://dev.max.ru/docs-api/use-cases/sending-messages/media/), [загрузка](https://dev.max.ru/docs-api/methods/POST/uploads/), [получение поста](https://dev.max.ru/docs-api/methods/GET/messages/-messageId-/).

## Проверка отправки

При сетевом сбое во время отправки площадка могла принять пост или ответ. В этом случае Salavat отмечает исход как неопределённый, чтобы редактор мог проверить публикацию на площадке. MAX допускает ограниченный повтор с теми же вложениями, если в ответе прямо сообщено, что файл ещё обрабатывается. [Отправка медиафайлов в MAX](https://dev.max.ru/docs-api/use-cases/sending-messages/media/#vozmozhnye-oshibki-pri-otpravke-vlozheniya-v-soobschenii).
