## Проверено

- Полный набор: **361 тест прошёл**. Проверки охватывают изоляцию компаний, роли, источники, очереди, согласование, денежные резервы, миграции, повторные события и адаптеры с подставными внешними API. Осталось предупреждение библиотеки тестового HTTP-клиента об устаревающем способе подключения.
- TypeScript и Vite собираются. Новые экраны исследований, стратегии, Telegram, CRM и расходов проверены в браузере на отдельной тестовой базе; калькулятор пересчитывает введённые цены.
- Реальный поиск, MTProto и CRM ещё требуют доступа пользователя и проверки на его тестовых системах. Сохранение ключа не считается подтверждением работоспособности интеграции.

Для проверки новых разделов откройте кабинет аккаунтом администратора компании или редактора. Главному администратору редакционные данные недоступны по установленным правилам.

## Тестовый туннель

`server.tunnel_runner` запускает только уже настроенный localhost.run, использует `.runtime/ssh-tunnel-config` и восстанавливает соединение после отключения. Новый адрес подхватывают кабинет и меню бота. Он не запускается автоматически после перезагрузки Windows. Остановить повторные подключения можно созданием пустого файла `.runtime/tunnel.stop`; для следующего запуска удалить этот файл. Временный адрес не заменяет постоянное размещение сервера.
