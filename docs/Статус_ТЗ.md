## Проверено

- Полный набор: 243 автоматических теста. Изоляция компаний, роли, источники, повторные запросы, очереди, согласование, тайм-ауты и адаптеры проверялись с подставными внешними API.
- TypeScript и Vite собираются. Браузерный сценарий прошёл на временной базе: старые функции фото/логотипа, база знаний, задача, план, обращения, статистика и мобильная ширина 390 px.
- Реальная задача №1 в рабочей компании через настроенную модель ответила про день рождения завода — 30 июня 1962 года — с цитатой из источника. Был выполнен один текстовый запрос. Публикации для этой проверки не создавались и в каналы не отправлялись.
- Рабочая база сохранена в `.runtime/backups/salavat-before-features-20261114-143724.sqlite3`. Добавлено пять активных записей и два черновика.

Для проверки новых разделов откройте кабинет аккаунтом администратора компании или редактора. Главному администратору редакционные данные недоступны по установленным правилам.

## Тестовый туннель

`server.tunnel_runner` запускает только уже настроенный localhost.run, использует `.runtime/ssh-tunnel-config` и восстанавливает соединение после отключения. Новый адрес подхватывают кабинет и меню бота. Он не запускается автоматически после перезагрузки Windows. Остановить повторные подключения можно созданием пустого файла `.runtime/tunnel.stop`; для следующего запуска удалить этот файл. Временный адрес не заменяет постоянное размещение сервера.
